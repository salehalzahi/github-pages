قرية حميم هي قرية سعودية تتبع لمحافظة بني حسن في منطقة الباحة، المملكة العربية السعودية. تتميز القرية بجمال الطبيعة وتنوع الثقافة، وتعتبر مركزًا للاستيطان القبلي في المنطقة.

_الأماكن السياحية_

1. شلالات جدر: شلالات طبيعية جميلة.
2. سد وادي العامر: سد يخدم المنطقة.
3. غابة جدر: غابة كثيفة.

_العادات والتقاليد المحلية_

1. العرضات الشعبية: عروض ثقافية تقليدية.
2. الماكولات الشعبية: الخبزة، العصيدة.
3. الاحتفالات التراثية: احتفالات تقليدية.

_الخدمات الصحية_

1. مركز صحي حميم زهران: مركز صحي يخدم السكان.

_الشاليهات_

1. شاليهات البحيري: شاليهات سياحية.

_الشخصيات البارزة_

1. صالح علي سعيد الزاهي الزهراني.
2. عبدالله علي سعيد الزاهي الزهراني.
3. مطير محمد مطير الزهراني.
